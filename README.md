# Rogue Dawn: the score

This branch collects the soundtrack of [Rogue Dawn](https://github.com/virtu333/rogue-emblem), a
Fire Emblem-style tactics roguelike: the music, the code that composes it, and the game code that
plays it. Every note is original and written as code. There are no DAW projects: each piece is a
Python score, rendered by a small orchestral engine from free sample libraries. The scores are also
exported as MIDI files (`midi/`), to play on any synth or load into a DAW or notation program.

It is a snapshot of the game's `main` branch; the files keep their paths from the game repo, so
anything here can be found there too, except the MIDI export (`tools/music/midi.py` and `midi/`),
which was added on this branch. The game itself is at https://emblem-rogue.netlify.app.

## What's here

| Path | What it is |
|---|---|
| `tools/music/SCORE.md` | **Start here.** The music itself: the leitmotifs, every cue and what it does, the device budget, how battles pick their music |
| `tools/music/README.md` | Setup, build and the analysis tools |
| `tools/music/scores/` | 43 loop scores (battle, boss, map, menu themes), one Python file each, with a program note at the top |
| `tools/music/stingers/` | 30 ceremony cues (level-up, promotion, boss cards…). 14 of them are rendered in every key the music uses, so they land in the key of whatever is playing |
| `tools/music/engine/` | The engine: the score notation, patterns and voice leading, the sampler, the mixer, loop export |
| `assets/audio/music/` | The rendered loops (76 files, MP3): each piece, plus a calm mix for every adaptive battle theme and an enrage layer for every boss |
| `assets/audio/stingers/` | The rendered ceremony cues (142 files) |
| `midi/` | Every loop and ceremony cue as a Standard MIDI File (106 files), exported from the scores: a track per part, General MIDI sounds, loop markers. `midi/README.md` lists them |
| `src/` | How the game plays it (below) |
| `tests/` | The game's music tests. They run inside the game repo, not on this branch |

## Listening

Every file in `assets/audio/music/` is named after its cue; the cue list in `SCORE.md` gives each
one's title and what it's doing. Some to start with:
- `music_title`: the main theme.
- `music_battle_act1`: Ember Dusk, the main battle theme. Its `_calm` twin shares the same
  timeline.
- `music_boss_entity` then `music_boss_entity_finale`: the secret final boss, and the finale that
  cuts in at its first wound.
- `music_run_win`: where the main theme finally resolves.

Each file is an intro followed by a loop. The game loops it seamlessly at the points in
`src/utils/musicLoops.js`, so a plain media player plays each file once, through the jump.

## How the game plays it

| File | Role |
|---|---|
| `src/utils/musicConfig.js` | Which track plays where, the adaptive layers, the boss cards, the Entity's finale |
| `src/utils/AudioManager.js`, `LoopedMusic.js`, `StingerPlayer.js` | Web Audio playback: sample-accurate intro + loop, layers started on one clock and crossfaded mid-loop, stingers in the current key that duck the music |
| `src/engine/MusicIntensity.js` | When a battle goes from calm to full and back (blows exchanged, threat in range) |
| `src/engine/BattleMusicSelection.js` | Which theme a battle plays: the situation, the place, the act; hashed from the run seed, so a resumed battle keeps its music |
| `src/ui/BattleMusicController.js` | Drives all of it during a battle, including boss enrage and the Entity's finale hand-off |
| `src/engine/FinaleRally.js` | The army's lines over the finale, one every two bars |
| `src/utils/musicLoops.js`, `musicStingers.js` | Generated by the build: loop points, keys, stinger hand-offs |

These files are excerpts from the game and import a few game modules that aren't on this branch.

## Rendering it yourself

Follow `tools/music/README.md`. In short: Python 3 with `numpy scipy numba soundfile pyloudnorm
mido matplotlib`, `ffmpeg` and `fluidsynth`, `sfizz_render` for the drum kit, bass and piano, then
`bash tools/music/fetch_libraries.sh` to download the sample libraries (about 9 GB), and:

```bash
python3 tools/music/build.py battle_act1 --preview   # one score, plus previews through the loop jump
python3 tools/music/build.py --all                   # everything
```

## Sample libraries

The renders use free libraries fetched by `fetch_libraries.sh`: VSCO 2 Community Edition,
GeneralUser GS, Virtuosity Drums, Karoryfer Growlybass and the Splendid Grand Piano. They are not
included here; each comes with its own license, in its own repository.
