# Player sprite set 2

Five classes, two player appearances each: Archer, Mage, Cleric, Fighter, Knight.
Open index.html for actual-renderer map comparisons, grayscale, stone and silhouettes.
Sources and exact built-in imagegen prompts are in sheets/ and catalog.json.
The source files are preserved; sprites/ contains nearest-neighbor renderer-sized
textures using current spritePlacement. Ten variants, zero alpha-cut warnings.
All five comparison controls and sixteen displayed images checked; no broken images.

Edric, Sera and Pegasus Knight remain unchanged comparison anchors. Map positions
are staged art probes in an isolated muted browser. HUD counts describe the original
fixture. Stone uses an art-only overlay. No game code, production assets or saves changed.

Mage is visually small and warrants user review. Fighter, Cleric and Knight have
stronger class cues in this view. Live acted state, fog, range overlays, animation
and real-device checks remain pending. Temporary server stopped after captures.
