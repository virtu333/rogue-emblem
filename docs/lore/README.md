# Rogue Dawn lore

**Status: draft, 2026-11-09.** Built on the "un-lived time" story direction, which the owner has not yet confirmed. Until he does, nothing here is canon and no game text should be written from it.

This folder is the world's reference. `docs/lore-style-guide.md` says how lore is written; this says what is true.

## How to read it

Every fact carries one of three marks.

- **[in game]** The game says this today. The file or line is named where it helps.
- **[new]** This document adds it. It contradicts nothing in the game, but no text says it yet.
- **[sealed]** True, but no text may state it outright before the special ending. Lines may come close.

When the game and this folder disagree, the game wins and this folder is wrong. Fix the folder.

## History

An earlier world bible (pull request #119, September 2026) was built on a different engine, in which people keep, spend or feed their names. It was never merged and the game moved on without it. Its geography, its old kings, its boss histories and its "names returned" feature are carried into this version; its cosmology is not. The review that led here is `reviews/lore-pass-review.md` in the project files.
