Reward screen — icons and rarity

Proposal only. Nothing here is wired into the game. Colors are the live tokens from src/ui/uiPalette.json; the two new ones are marked NEW. Icons are inline SVG on a 16×16 integer grid with shape-rendering: crispEdges, so they read as pixel art, tint from currentColor, and need no new art assets or preloading.

1 — rarity ladder

Five steps, mapped straight onto the tier field that already exists on all 122 entries in weapons.json (Iron / Steel / Silver / Rare / Legend). Nothing to invent for weapons. Gold keeps --re-accent and sits outside the ladder because it is currency, not an item.

4 — what a row costs

tokens added to uiPalette.json 2 (rarityEpic, rarityLegend) tokens reused 3 (muted, good, info) new SVG glyphs 9 inline, ~120 bytes each, no assets new data fields 0 for weapons (tier already exists) 1 optional: tier on accessories.json / consumables.json shared module src/ui/rewardDisplay.js -> rarityOf(choice), rewardIcon(type)

rarityOf() should live beside rosterDisplay.js and be the single definition, the same way formatPerkMods was extracted. Weapons read tier; everything else falls back to a pool-to-rarity map keyed on choice.type, so no content edit is required to ship it. Adding tier to accessories and consumables later upgrades the fallback without touching the UI.
