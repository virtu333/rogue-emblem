UI cohesion pass

Mockups for bringing the pre-mobile screens onto the language established by the mobile rebuild. Every frame below is 844×390 — iPhone 14 Pro landscape, the size mobileBattle.css already pins the dev preview to. All frames are real HTML driven by re-kit.css in this folder, which is the proposed replacement for mobileTheme.css.

1 · Tokens

The existing theme has 14 tokens but the code uses roughly 60 literal hexes around them — six golds, three muteds, two scrim hues. mobileUpgrade.css (which drives Home Base, Upgrades and Rewards) does not import the theme at all and uses zero var(). The kit below closes that, adds the tokens that were being faked with literals, and keeps every value already in use except where two values clearly meant to be one.

4 · Node map

Act 1

Border skirmishes

200 G Normal

Battle · Rout

6 enemies · Lv 1–2 · Plains

Edric 20/20 Sera 10/16

The biggest live problem. On a phone today the node map is a 640×480 letterboxed canvas floating in black, flanked by the original index.html rail buttons — black fill, white monospace, 4px radius — which belong to neither style. This frame shows the rail restyled with .re-rail so it reads as part of the same product, the header/gold/difficulty row promoted out of 10px canvas text into real HTML, and the party bar using the same HP meter as the battle HUD. Node art is the real cost: the node glyphs are sprites (node_battle.png …) and the auras use BlendModes.ADD, which behaves differently over #192f3b than over near-black. Recolouring constants is a day; re-authoring the node set and re-tuning the auras is the schedule risk.

7 · Blessing select — the tier problem

Choose a blessing

One pick · shapes the whole run

The one place the palette genuinely fights the design. BlessingSelectScene.TIER_COLORS currently gives each tier its own background, border and label — twelve values spanning green / blue / orange / red. Flattening that into a single teal system loses the at-a-glance tier read. The proposal here: shared panel background, tier communicated by a 4px left border + a roman-numeral badge, with the four tier hues surviving as accents only. This needs a design call, not just a find-and-replace — flagging it as the one item in this pass I would not decide unilaterally.
