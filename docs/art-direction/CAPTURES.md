# Review captures

The folders here keep a curated set of captures (about 9 MB) so the repository stays light.
The complete review sets (before/after sheets for every map, viewport and device scale,
animation loops, and the original direction-board studies, about 78 MB) are preserved in
git history at commit `94831bc`:

https://github.com/virtu333/rogue-emblem/tree/94831bc/docs/art-direction

Every set can also be regenerated with the tool named in its folder's README (for example
`node tools/art/procedural-terrain/generate.mjs`, `node tools/art/pc98/capture.mjs`,
`node tools/art/captureCeremonies.mjs`, `node tools/art/captureGrowth.mjs`). A README
link to an image that is not in the folder refers to that commit.
