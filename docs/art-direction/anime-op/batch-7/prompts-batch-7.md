# Cutscene art: GPT image prompts, batch 7 ("The Ford")

Style: **The Unwritten Page** ([STYLE.md](STYLE.md)). These are for the vertical slice
planned in [FORD.md](../../../tools/cutscene/unwritten/FORD.md): Edric against the
Empire's spearman (the Warden) in a river ford. The slice is built first with the art we
already have. These images replace its stand-ins: the Warden has no poses beyond the
clash clip, and nobody has the slide, the burst or the yield.

**Send each prompt exactly as written.** Key poses come as **pose sheets**: several
poses of one figure in a row, at the same scale, on one ground line. One image keeps
the character consistent between poses, and code cuts the poses apart.

## After generating

Drop the images into the local folder as before. The local session keys the pose
sheets into `cutouts/` (one file per sheet; code splits the poses at the green gaps)
and adds catalogue rows. Good pose sheets can then be sent to MiniMax as first and last
frames (`motion/jobs.json`): guard to thrust, the yield to the cut, the slide to the
burst.
